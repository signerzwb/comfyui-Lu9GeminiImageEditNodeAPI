# comfyui-lu9-VisonApi-9images

这是一个独立插件，不挂在 `lu9-Gimagev1` 下面。

节点名：

- `lu9-VisionApi 9images`

分类：

- `lu9-VisionApi`

特点：

- 最多支持 `9` 张图
- 主组：
  - `api_url`
  - `model`
  - `api_key_1`
  - `api_key_2`
  - `api_key_3`
- 备组：
  - `backup_api_url`
  - `backup_model`
  - `backup_api_key_1`
  - `backup_api_key_2`
  - `backup_api_key_3`
- 上面这些 url、model、key 默认都是空字符串，不预填

自动容灾逻辑：

- 先跑主组
- 主组内部按 `api_key_1 -> api_key_2 -> api_key_3`
- 如果主组整体失败，再自动切到备组
- 备组内部按 `backup_api_key_1 -> backup_api_key_2 -> backup_api_key_3`

状态输出：

- `status_text` 会显示当前实际使用的是主组还是备组
- `status_text` 会显示当前实际使用的是哪一个 key

请求方式：

- OpenAI 兼容 `chat/completions`
- 图片会转成 `data:image/png;base64,...`
- 每张图前会自动插入：
  - `[Image 1]`
  - `[Image 2]`
  - ...
  - `[Image 9]`

输出：

- `response`
- `raw_response`
- `status_text`
